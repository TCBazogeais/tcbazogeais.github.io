# TC Bazogeais – Portail championnat

Page des joueurs du TC Bazogeais : dates de championnat et disponibilités.

👉 **https://tcbazogeais.github.io**

Cette page est une copie de `Index.html` du dépôt du projet. Les données (rencontres, joueurs, réponses) sont dans la Google Sheet du club et passent par Apps Script : ce dépôt ne contient aucune donnée ni aucun secret.
